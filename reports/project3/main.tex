    \item Added method signatures for the new methods added in \textbf{/pintos/threads/threads.c}

\subsection*{/pintos/devices/thread.c}

\begin{itemize}
    \item (\textit{added}) \textbf{Includes}:
    \begin{itemize}
        \item threads/fpr\_arith.h
        \item devices/timer.h
    \end{itemize}
    \item (\textit{added}) \textbf{Global variable}:
    \begin{itemize}
    \item \textbf{FPReal load\_avg}, this stores the system load average
    \end{itemize}
    
    \item (\textit{modified}): \textbf{void thread\_tick}; Added the check for the -mlfqs option according to given specs (to handle recent\_cpu, priority, load\_avg)
    
    \item (\textit{modified}): \textbf{tid\_t thread\_create(void)};
    Added the check for the -mlfqs option, set default nice value and recent\_cpu value. Update priority and check for the priority of the new thread and if necessary, yield current thread.

    \item (\textit{added}): \textbf{void thread\_unblock};
    We inserted the thread in an ordered way in the \textbf{ready\_list} instead of just pushing it back. This is to ensure that \textbf{ready\_list} is ordered such that the head of the list has the highest priority thread.

    \item (\textit{added}): \textbf{static bool compare\_priority};
    Compares the priorities of two threads t1, t2 and returns true if t1 has a higher priority than t2. We use this when calling \textbf{list\_insert\_ordered}
    
    
    \item (\textit{modified}): \textbf{void thread\_yield};
    We inserted the thread in an ordered way in the \textbf{ready\_list} instead of just pushing it back. This is to ensure that \textbf{ready\_list} is ordered such that the head of the list has the highest priority thread.

    \item (\textit{modified}): \textbf{void thread\_set\_priority};
    We update the priority of the current thread. Check if it's necessary to yield comparing current with the top of the \textbf{ready\_list}. Check for the -mlfqs option (in that case, the method is ignored because in -mlfqs mode the priority is computed based on nice values and recent\_cpu);

    \item (\textit{added}): \textbf{void thread\_set\_nice};
    Updates the current thread nice value and updates priority based on that. If necessary, yield.
    
    \item (\textit{modified}): \textbf{int thread\_get\_nice};
    Get the current thread's nice value.
    
    \item (\textit{modified}): \textbf{int thread\_get\_load\_avg};
    Compute and return the system load average.
    
    \item (\textit{modified}): \textbf{int thread\_get\_recent\_cpu};
    Compute and return the current thread's recent CPU value.

    \item (\textit{added}): \textbf{void update\_load\_avg};
    Computes and sets the system load average.

    \item (\textit{added}): \textbf{thread\_action\_func * thread\_update\_recent\_cpu};
    Computes and updates the recent CPU value of the given thread. Used in the \textbf{thread\_tick} method, for each thread. 
    
    \item (\textit{added}): \textbf{thread\_action\_func * update\_priority};
    Computes and updates the recent thread priority. Check if computed value is in valid range using constants defined previously. Used in the \textbf{thread\_tick} method, for each thread.

\end{itemize}
