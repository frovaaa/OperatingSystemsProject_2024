\section{Changes}

\subsection*{/pintos/thread/sleepy\_thread.h}

\begin{itemize}
    \item Created this header file declaring \textbf{struct sleepy\_thread} in order to create a list with \textbf{lib/kernel/list.h}. The struct is built to accommodate the requirements of \textbf{list.h}, it contains: as a first element the mandatory \textbf{struct list\_elem elem}, a \textbf{struct thread * thread\_p} that points to the current thread which needs to be put to sleep, an \textbf{int64\_t awake\_time} (which represents when a thread needs to be woken up in terms of absolute ticks).
\end{itemize}

\subsection*{/pintos/devices/timer.c}

\begin{itemize}
    \item (\textit{added}) \textbf{Includes}:
    \begin{itemize}
        \item threads/sleepy\_thread.h
    \end{itemize}
    \item (\textit{added}) \textbf{Prototypes}:
    \begin{itemize}
    \item static bool compare\_awake\_time(const struct list\_elem *le1, const struct list\_elem *le2, void *aux UNUSED): this is to avoid warnings after compilation.
    \end{itemize}
    
    \item (\textit{added}): \textbf{static struct list sleepy\_threads\_list}; This global variable is needed to store the threads that are currently blocked and are waiting to be unblocked after \textbf{awake\_time} ticks. It's declared \textbf{static} in order to make it accessible only from methods in \textbf{timer.c}. The variable is in shared memory, so threads calling the method \textbf{timer\_sleep(int64\_t ticks)} can access and modify it.
    
    \item (\textit{modified}): \textbf{void timer\_init(void)};
    We initialize the \textbf{struct list sleepy\_threads\_list} here because we wanted it to be done as soon as possible and this is the first method that runs when using timer.c

    \item (\textit{added}): \textbf{static bool compare\_awake\_time(const struct list\_elem *le1, const struct list\_elem *le2, void *aux UNUSED)};
    This method is needed to use the \textbf{list\_insert\_ordered} method declared in \textbf{list.h}. It takes two \textbf{struct list\_elem *} and checks whether \textbf{le1} (list\_element 1) needs to be awakened before \textbf{le2} (list\_element 2). This is done by comparing the two \textbf{awake\_time} fields of the elements.

    \item (\textit{modified}): \textbf{void timer\_sleep(int64\_t ticks)};
    \begin{itemize}
    \item Disabled interrupts when entering critical section;
    \item For the \textbf{current thread}, it computes its \textbf{awake\_time} by summing the current tick time and the desired sleep duration that is passed as parameter \textbf{ticks};
    \item It inserts the current thread in the \textbf{struct list sleepy\_threads\_list} according to its \textbf{awake\_time} field.
    \item It calls the \textbf{thread\_block()} to block the current thread.
    \item When exiting the critical section (thread unblocked) we re-enable interrupts
    \end{itemize} 
    
    
    \item (\textit{modified}): \textbf{static void timer\_interrupt(struct intr\_frame \*args UNUSED)};
    \begin{itemize}
    \item Disabled interrupts when entering critical section;
    \item Iterating through the \textbf{struct list sleepy\_threads\_list}:
    we check if there are threads that need to be unblocked by accessing the dedicated field of the list element (\textbf{awake\_time}) and if needed we unblock them by calling the method \textbf{thread\_unblock(struct thread *t)}.
    \item When exiting the critical section we re-enable interrupts
    \end{itemize}
    
\end{itemize}
