\section{Changes}

\subsection*{/pintos/threads/thread.h}

\begin{itemize}

    \item \textit{(added)} \textbf{import} of threads/synch.h
    \item \textit{(added)} \textbf{#define} for \textbf{cur\_status} field of \textbf{struct child\_elem }
    \item \textit{(added)} to \textbf{struct thread}:
        \begin{itemize}
            \item \textbf{struct list child\_list} list of all child threads of a thread
            \item \textbf{struct semaphore child\_load} when is < 0, the current thread is blocked and waiting for its child to finish loading. 
            \item \textbf{struct semaphore child\_exit} when is < 0, the current thread is blocked and waiting for its child to terminate.
        \end{itemize}
    \item \textit{(added)} \textbf{struct child\_elem} that is used to represent child threads in \textbf{struct list child\_list}, it holds information about the status of the child (pid, if it's the first time its parent is waiting for it, current status, if it loaded successfully)
    \item \textit{(added)} signature for \textbf{struct child\_elem * thread\_get\_child(struct thread * parent, tid\_t child\_tid}

\end{itemize}

\subsection*{/pintos/devices/thread.c}

\begin{itemize}
    \item (\textit{added}) \textbf{struct child\_elem * thread\_get\_child(struct thread * parent, tid\_t child\_tid}, given a \textbf{struct thread *} to a parent thread and a \textbf{tid\_t} of a child thread, returns the \textbf{struct child\_elem *} if the parent contains that child\_tid in its child\_list or null if it doesn't.

    \item (\textit{modified}) \textbf{tid\_t thread\_create (const char *name, int priority, thread\_func *function, void *aux)}:
          We added the initialisation of the \textbf{struct child\_elem *} by allocating the necessary memory and setting the default value of its fields. Then we push it into the \textbf{child\_list} of the current thread.
    \item (\textit{modified}) \textbf{static void init\_thread(struct thread * t, const char * name, int priority)}: We initialised the parent to null, the semaphores with a 0 initial value and the child\_list.
\end{itemize}

\subsection*{/pintos/userprog/process.c}

\begin{itemize}

    \item (\textit{modified}) \textbf{static void start\_process (void *file\_name\_)}:
          Increase the child\_load semaphore of the child of the current thread because it means that the child (the current thread) has finished loading. Set the successful\_load field of the child (which can be either true or false) to signal that the child was successfully loaded (or wasn't).

    \item (\textit{modified}) \textbf{int process\_wait(tid\_t child\_tid)}:
          Replaced the block/unblock with the semaphores: if the child process is alive, the parent will decrease the child\_exit semaphore of its child, blocking itself while waiting for the child to finish execution.
    \item (\textit{modified}) \textbf{void process\_exit(void)}:
    \begin{itemize}
        \item It prints the tests exit statements.
        \item If the current thread has a parent (it is a child thread), it updates its data into the child\_list of the parent (setting its current status to KILLED and exit status to -1). Removes its child\_list and deallocates the memory, removes itself from its parent list, remove its own parent.
    \end{itemize}
    
\end{itemize}




\subsection*{/pintos/userprog/syscall.c}

\begin{itemize}
    \item (\textit{added}) \textbf{import} of userprog/pagedir.h
    \item(\textit{modified}) added the handlers reference for wait() and exec().
    \item (\textit{added}) \textbf{static void syscall\_wait(struct intr\_frame *f)}:handles the wait system call, calls \textbf{process\_wait} on the pid popped from the stack.
    \item (\textit{added}) \textbf{static void syscall\_exec(struct intr\_frame *f)}: pops the program pointer from the stack and checks if it's valid, if it's not valid, pushes -1 and calls syscall\_exit. Checks if the current page dir of the given program is null, if it is, pushes -1 and calls syscall\_exit. Now that we have checked that the given program is valid, call process\_execute which will create a child and run it. Decreases the child\_load semaphore of the newly created child. If the child was successfully loaded, returns the pid of the child.
    \item(\textit{modified}) \textbf{static void syscall\_exit(struct intr\_frame *f}: If the current thread has a parent (it is a child thread), it updates its data into the child\_list of the parent (setting its current status to KILLED and exit status to EXITED.
    
\end{itemize}
